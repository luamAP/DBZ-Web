# Governança do Repositório

- `logs/`, `__pycache__/`, `.env` e temporários no `.gitignore`.
- Dependência externa nova vai para `requirements.txt`.
- Arquivo ou diretório novo: atualizar `arquitetura.md` na mesma iteração.
